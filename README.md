# 为她所听（music_perception）

N.E.K.O 的电脑音频感知插件：让角色听得见、听得懂。

采集系统或指定应用的声音 → 识别正在播放的歌曲与歌词 → 视频语音转写 →
专业歌声识别 → 人声/伴奏分离试听。所有模型按需下载，进度可见。

## 能做什么

- **听歌识曲**：认出正在放的歌，跟随时间轴滚动歌词
- **视频语音**：转写视频里说的话，作为理解画面的证据
- **专业歌声识别**：中日英四档（Whisper / Qwen3-ASR），按显存自动选档
- **人声分离**：四档声部分离模型，分离后可试听原声与增强结果
- **应用声道**：只听你指定的那个软件，通知和别的窗口不会混进来
- **AI 私有感知**：静默提交，不直接发聊天消息
- **律动**：角色跟着音乐轻轻摆动（只用已有频谱，不额外推理）
- **新手引导**：首次打开带你检查环境、选安装位置、挑配置，每项下载都有进度条

## 安装

在 N.E.K.O 插件市场搜索「为她所听」安装，或把本仓库克隆到插件的
`.neko-plugin-installations/plugins/music_perception` 目录。

首次打开面板会进入新手引导：检查环境 → 选模型存放位置 → 选配置 → 下载。

## 环境

Windows 10/11。GPU 可选（NVIDIA 显存 ≥4GB 可开 CUDA 加速），CPU 也能跑。

## 隐私

全程本地处理。模型从公开源下载（国内/国外双源可选），音频不上传、
不需要账号。截图与语音只在你的机器上分析，结果只用于角色理解。
