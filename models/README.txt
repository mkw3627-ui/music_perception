No model is included in this source ZIP.

After you register the source through N.E.K.O Development, the explicit
"自动编译并安装" button downloads a YAMNet TFLite model locally and runs
a real native inference preflight. If model or dependencies are incompatible,
the official N.E.K.O package build and install are NOT attempted.

The user must separately authorize speaker loopback monitoring in the
installed plugin panel. No microphone fallback and no background audio
capture from the act of building/installing alone.
